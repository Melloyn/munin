# Privacy

Munin is local-first.

## Local Storage

Munin stores data locally on your Mac by default:

```text
~/Library/Application Support/munin
```

Tasks, lists, notes, subtasks, reminder metadata, and attachment metadata are stored locally. Attachments are copied into Munin's local app storage.

## Cloud Sync

Munin v3.0 beta does not include cloud sync.

## Telemetry

Munin v3.0 beta does not implement telemetry or analytics.

## Backups

Backups are created only when the user chooses `Экспорт резервной копии`. Backup files are stored in the destination selected by the user.

Do not upload backup folders publicly if they contain private tasks, notes, or files.
