# Regression Test Skill

Use before final response after any code change.

## Commands

```bash
node --check main.js
node --check preload.js
npm start
npm run build
```

If a command cannot run, report why.

## Manual Checks

- Create today and tomorrow tasks.
- Verify list, 7-day, and calendar date placement.
- Drag task between days.
- Complete/reopen tasks; verify counts and Today progress.
- Create/rename/delete/check lists.
- Attach PDF, DOCX, DOC, XLSX, TXT/MD, image.
- Preview files, open in system, delete attachment.
- Restart app and verify persistence.

## Final Report

Always include changed files, commands run, manual checks, untested items, and limitations.
