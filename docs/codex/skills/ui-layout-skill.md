# UI Layout Skill

Use for layout, task details, preview placement, or responsive UI tasks.

## Main Rule

Details and attachment previews must be below the active view, not in a right panel.

## Required

- Sidebar remains left.
- Main content fills available width.
- List/7-day/calendar appear above the bottom details panel.
- Bottom panel shows selected task details and attachments.
- Page or preview cards scroll vertically when content is long.

## Forbidden

- Right details sidebar.
- Split view with details column.
- Fixed/absolute details panel.
- Horizontal page scroll caused by previews.

## Tests

Select tasks in List, 7-day, and Calendar. Confirm lower panel updates, selected task is highlighted, and long previews do not break layout.
